# Micro-SaaS de Controle de Entregas

Bootstrap inicial do primeiro produto E2E da Fábrica.

## Stack

- React 19
- Vite 7
- TypeScript 5
- Vitest 3
- Supabase JS 2

## Objetivo

Centralizar entregas, responsáveis, prazos e status para pequenas equipes de logística urbana.

O bootstrap não implementa ainda as regras de negócio nem o banco do produto.
